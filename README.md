# ウマ娘 7th EVENT in TOKYO グッズ被弾チェッカー

ウマ娘 7th EVENTの物販に向けた、非公式のグッズ購入計算（被弾チェック）ツールです。
購入予定のグッズの数量を管理し、合計金額の計算や、購入リスト作成を簡単に行うことができます。

**公開URL:** https://nyaftama.github.io/uma7th-item-search/

## 主な機能

* **合計金額の自動計算**
  * グッズの数量（＋/－/MIN/MAX）を操作することで、リアルタイムで総購入点数と合計被弾額を算出します。
* **検索と絞り込み**
  * **サジェスト機能:** 検索窓に入力する過程で、グッズ名やキャラクター名の候補を最大3件リアルタイム表示します。
  * **ワンタッチ検索:** 各グッズに付与されたキャラクター名のバッジをタップすると、そのキャラクターのグッズのみを即座に絞り込めます。
* **トレーディング商品の排他制御**
  * トレーディング商品（ランダム商品）を購入リストに追加した際、同名の別キャラクターの行は自動的にロック（半透明化）され、重複して数量を入力してしまうのを防ぎます。
* **レシート風画像のシェア機能**
  * カートの中身をレシート風の画像としてブラウザ上で自動生成します。長押しや右クリックで保存し、ワンタップでX（Twitter）へハッシュタグ付きでシェアすることが可能です。

## 技術スタック

* **HTML / CSS / Vanilla JavaScript** (フレームワーク不使用)
* **[PapaParse](https://www.papaparse.com/)**: CSVファイルの読み込み・パース
* **[html2canvas](https://html2canvas.hertzen.com/)**: DOMからのシェア用画像生成

## ファイル構成

* `index.html`: メインのアプリケーションコード（UI、ロジック、スタイルシートがすべて含まれています）
* `items.csv`: グッズの一覧データ（グッズ名、入手タイプ、金額、トレーディングフラグ、最大数量など）
* `color.csv`: ウマ娘のイメージカラーデータ（メインカラー、サブカラー）※バッジのツートンカラー描画に使用

## データの更新方法

グッズ情報やキャラクターの色情報を更新したい場合は、対応するCSVファイルを編集してリポジトリにプッシュするだけで、アプリケーション側に即座に反映されます。

1. `items.csv` に新しいグッズの行を追加・修正します。
2. `color.csv` に新しいキャラクターの名前とカラーコード（HEX形式）を追加します。
